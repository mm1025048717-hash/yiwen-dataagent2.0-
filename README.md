# 亿问DataAgent 2.0

智能数据分析助手，集成DeepSeek API提供强大的对话能力。支持数字分身（AI员工）的价值量化评估体系。

## 功能特性

- 🎯 智能问答：基于DeepSeek大模型的自然语言对话
- 📊 数据可视化：支持多种图表和数据分析
- 🔄 多模型支持：支持deepseek-chat和deepseek-reasoner两种模型
- 💬 对话历史管理：支持多轮对话上下文记忆
- 🤖 **AI员工管理**：创建、配置和管理数字分身
- 📈 **价值评估体系**：KPI/OKR双模式的AI员工绩效量化评估

## ⭐ 新功能：AI员工价值评估机制

### 核心理念

将传统员工评估模式转变为数字分身价值量化模式，实现：
- **评估转型**：从评价物理员工 → 评价其数字分身创造的直接/间接价值
- **价值量化**：建立可追溯、可审计的价值核算规则
- **激励优化**：激励员工主动优化分身能力，形成良性循环
- **流程延续**：确保工作转接、协作中价值不断档

### 双模式评估体系

#### 📊 KPI 模式（结果导向）

基于关键绩效指标进行价值量化：

| 价值类型 | 对应工作 | 核心指标 | 默认权重 |
|---------|---------|---------|---------|
| 基础响应价值 | 客户咨询应答、内部流程指引 | 响应率、平均耗时 | 25% |
| 事务办结价值 | 合同初审、报销单校验、数据统计 | 独立办结率、处理准确率 | 45% |
| 协作省心价值 | 异常转接处理、跨部门信息拉通 | 转接降低率、辅助成本节约 | 30% |

**特性**：
- ✅ 可自定义KPI标题、描述和权重
- ✅ 支持动态添加/删除评估指标
- ✅ 实时显示权重总和校验

#### 🎯 OKR 模式（成长导向）

设定周期性目标与关键结果：

**示例目标 O1**：提升分身复杂事务处理能力
- KR1: 本月分身复杂事务推进率 ≥ 30%
- KR2: 复杂事务处理准确率 ≥ 85%
- KR3: 新增复杂事务知识库条目 ≥ 20 条

**示例目标 O2**：降低分身转接率与本人辅助成本
- KR1: 月度转接率 ≤ 15%
- KR2: 本人辅助成本降低率 ≥ 25%
- KR3: 客户对分身处理满意度 ≥ 90 分

**特性**：
- ✅ 支持动态添加/删除目标(Objectives)
- ✅ 支持动态添加/删除关键结果(Key Results)
- ✅ 自动编号管理（O1, O2... / KR1, KR2...）

### 转接规则与价值归因

| 配置项 | 选项 |
|-------|------|
| 自动转接触发条件 | 分身无法解答2次时 / 事务紧急度≥90分时 / 涉及敏感权限时 |
| 转接后价值归因 | 按贡献比例计入分身（推荐）/ 全部计入分身 / 不计入分身 |

### 知识库价值关联

每个知识库条目可绑定价值属性标签，如：
- 📈 办结率
- ⚡ 响应率
- 🎯 准确率

上传高质量知识库可直接提升分身的"办结率"与"准确率"。

### 管理者视图

**团队价值中心**提供：
- 团队综合得分及趋势
- 分身价值排行榜
- 部门分身效能对比
- 待处理审核（错误扣减申诉等）
- 成本节约统计

## API接口说明

### 1. 聊天接口（非流式）

```
POST /api/chat
Content-Type: application/json

{
  "message": "用户消息",
  "conversationId": "可选，会话ID",
  "model": "deepseek-chat 或 deepseek-reasoner",
  "stream": false
}
```

### 2. 聊天接口（流式）

```
POST /api/chat/stream
Content-Type: application/json

{
  "message": "用户消息",
  "conversationId": "可选，会话ID",
  "model": "deepseek-chat 或 deepseek-reasoner"
}
```

### 3. 清除对话历史

```
POST /api/chat/clear
Content-Type: application/json

{
  "conversationId": "会话ID"
}
```

### 4. 健康检查

```
GET /api/health
```

## 使用说明

1. **智能问答**：在聊天界面输入问题，系统会调用DeepSeek API生成回复
2. **切换模型**：可以在理科生（deepseek-chat）和文科生（deepseek-reasoner）之间切换
3. **新建对话**：点击"新建问答"按钮开始新的对话会话
4. **仪表盘聊天**：在仪表盘界面也可以使用AI助手进行数据分析

## 注意事项

- API密钥请妥善保管，不要提交到代码仓库
- 对话历史目前存储在内存中，服务器重启后会丢失（生产环境建议使用数据库）
- 首次使用前请确保已安装Node.js和npm
